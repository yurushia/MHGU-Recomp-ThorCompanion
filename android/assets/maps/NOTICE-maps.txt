MHGU area maps (27 PNG files, 1024 x 1024 pixels)

maps/map_01.png ... map_27.png   the maps, unchanged from the MHGU Companion project
maps.csv                         id, name and file name of each map (Jurassic Frontier = 1, Verdant Hills = 2, ...)

The maps show the area numbers of each location. They were scaled up 4x from the originals so they stay sharp on
high-resolution screens (the files are not edited in any other way).
